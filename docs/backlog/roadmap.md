# Roadmap

## Phase 0: Operating system

- lock product brief enough to start implementation
- bootstrap Android project
- establish module skeleton
- add formatting, lint, and test tasks

## Phase 1: Core loop

- playable single puzzle session
- deterministic board state and move rules
- win and fail conditions
- retry and next-level flow

## Phase 2: Content and progression

- level definitions or generator pipeline
- progression save data
- level selection UI
- difficulty balancing

## Phase 3: Polish

- onboarding
- haptics, sound, and animation polish
- accessibility pass
- performance pass on target devices
